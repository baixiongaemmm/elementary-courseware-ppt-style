# Elementary Courseware & Designer PPT Style Skill

面向 **Antigravity / AI Agent** 的专业 PPT 视觉风格与排版技能包（`elementary-courseware-ppt-style`），沉淀自：

1. **小学数学 & 小学语文精品课 PPT 视觉规范**：基于抖音高赞基础教育精品课一等奖、AI 动态/3D 交互课件、说课图文与古诗/散文课型实地调研整理，包含精准 HEX 色板、字体规范、录课右侧 1/3 人像安全区及专属教学组件（顶部环节胶囊、思维对话气泡、先出题后出答案闯关层、米字格楷体写字卡、红圈段号批注层等）。
2. **设计师入职专属全色系模板库（12 套）**：自动提取自 12 套专业 `.pptx` 模板的完整视觉基因（绿色/蓝白/蓝色教学与技能大赛、橙色政务商务、红色金融总结、紫色国奖答辩、红白/黄色创赛路演、黑色芯片工科、黑金挑战杯及 160 页全色系版式库）。

## 目录结构

```text
elementary-courseware-ppt-style/
├── SKILL.md                           # 技能主入口与速查规范
├── references/
│   └── designer-templates.md          # 12 套设计师全色系模板精确色板、字体与版式指南
└── README.md
```

## 安装使用

将本仓库克隆至全局 Antigravity 技能目录即可自动按需激活：

```bash
git clone <your-repo-url> ~/.gemini/config/skills/elementary-courseware-ppt-style
```
