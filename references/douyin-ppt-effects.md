## 一、感觉鹿PPT（PowerPoint，粉丝 71.5 万）

定位：视觉设计向，核心手法是「形状 + 图片」的创意排版。

### 1. 梯形破格立体排版（11.0 万赞）
- **效果**：一张图片配一段文字，图片裁成上窄下宽的梯形并保留地面部分，下垫一个大矩形，画面有破格而出的立体感。
- **做法**：选中图片 → 在图片格式里用裁剪形状把图片裁成梯形（上面收窄）→ 再次裁剪保留地面 → 画大矩形置于底层 → 加上主文案。
- **适用**：封面页、一图一文主题页、课程/作品展示页。
- 来源：https://www.douyin.com/video/7612819922070763328

### 2. 电影谢幕式结尾页（36.6 万赞）
- **效果**：结尾不再写「感谢观看」：山水图铺满整页，超大加粗的 THANKS 居中，字母里填充同一张山水图，像电影谢幕字幕；与下一页之间用平滑切换过渡。
- **做法**：底图铺满 → 插入 THANKS 文字 → 放大加粗居中 → 给文字做图片填充 → 第二页加平滑切换（Morph）。
- **适用**：汇报、答辩、课程的结尾页与致谢页。
- 来源：https://www.douyin.com/video/7562766186339093800

### 3. 形状填充立体人物介绍（51.2 万赞，该博主最高赞）
- **效果**：人物照片填进斜切形状里，错落排版出立体层次；左侧书法标题 + 简介文字，背景是同一张照片的淡化版。
- **做法**：插入形状 → 形状格式填充选「图片或纹理填充」，把人物照片填进形状 → 斜切、错落排列 → 背景放同图淡化处理 → 左侧加标题与介绍文案。
- **适用**：人物介绍、非遗/传统文化、匠人主题。
- 来源：https://www.douyin.com/video/7654484817123861568

### 4. 波浪镂空层次封面（47.1 万赞）
- **效果**：右侧山水照片被波浪曲线形状镂空露出，沿曲线描金边，左侧留白放标题，层次分明。
- **做法**：波浪曲线形状做镂空层（形状与图片分层）→ 沿曲线描金边 → 切换/动画持续时间拉长（视频中为持续时间 8.00 秒、延迟 0.30 秒，慢速出高级感）。
- **适用**：文旅、地产、品牌封面。
- 来源：https://www.douyin.com/video/7690891054883936866

### 5. 泪滴形状图片填充（33.2 万赞）
- **效果**：三个大小不同的泪滴形状填入同一张森林照片，错落排在右侧，左侧放标题。设计关键点是大小对比。
- **做法**：插入形状选泪滴 → 填充图片 → 同一张照片填进不同大小的泪滴 → 旋转缩放、错落排列 → 左侧加标题。
- **适用**：创意封面、自然/环保主题、图片排版页。
- 来源：https://www.douyin.com/video/7696323860635146467

## 二、WPS PPT办公技巧（WPS，粉丝 29.9 万）

定位：功能教程向，核心手法是背景填充、蒙版、合并形状与平滑切换。

### 6. 背景填充过渡页（6.2 万赞）
- **效果**：照片做整页背景，中央多根竖向圆角矩形高低错落排列，上加文字，高级感过渡页。
- **做法**：新建幻灯片 → 右键「设置背景格式」→ 填充选「图片或纹理填充」插入照片 → 绘制圆角矩形，拖黄色控点调圆角弧度 → 复制多个、调整高度、错落摆放并对齐 → 加文字。
- **适用**：章节过渡页、目录后的分隔页。
- 来源：https://www.douyin.com/video/7410801215593876786

### 7. 蒙版：图片配文字的万能解法（7917 赞）
- **效果**：在图片上盖一层带透明度的色块（示例为蓝色渐变蒙版 + 白字），文字立刻清晰，图片边界变柔和，多张图片色调也被统一。
- **做法**：蒙版 = 盖在图片上的透明色块，分纯色、单色渐变、多色渐变三种；插入矩形盖住图片 → 填充渐变并调透明度 → 图层顺序为图片在下、蒙版居中、文字在上。专治三类问题：图片上文字看不清、图片边界生硬、图片色调不统一。
- **适用**：任何图片配文字的页面、卡片式排版、图多色杂的页面。
- 来源：https://www.douyin.com/video/7411525688370531623

### 8. 镂空文字电影级开场（6.5 万赞，该博主最高赞）
- **效果**：镂空大字透出背后的图片，配一句金句，电影海报式开场（也可作结尾页）。
- **做法**：画矩形 → 在矩形上输入文字 → 先选矩形、再按住 Ctrl 选文字（顺序不能反）→ 合并形状 → 剪除，得到镂空字 → 文字改为无轮廓 → 在镂空处衬入图片透出 → 再加动画。
- **适用**：发布会/汇报开场页、结尾页。
- 来源：https://www.douyin.com/video/7680547043051375881

### 9. 同心圆环旋转开场（5.9 万赞）
- **效果**：蓝色多层同心圆环（带十字镂空）居中旋转开场，科技感强。
- **做法**：画同心圆和加号 → 对齐后合并形状-剪除做成圆环 → 复制缩小做多层圆环并对齐 → 移到页面中央，填充图片、去除线条，背景用幻灯片背景填充 → 复制一页幻灯片，在第二页旋转圆环并加文字 → 给第二页加平滑切换（Morph）。
- **适用**：科技、发布会开场页，动态封面。
- 来源：https://www.douyin.com/video/7509107246886882587

### 10. 分层视差封面（3.4 万赞）
- **效果**：背景图、三角形形状层、文字层以不同速度运动，产生视差纵深。
- **做法**：设置背景图 → 绘制三角形分层 → 三角形加阴影（视频参数：黑色、透明度 20%、大小 105%、模糊 100 磅、距离 0、角度 0）→ 给三角形、背景图、文字分别设置动画（分层动画/平滑切换，速度错开）；操作时需同时选中两个三角形一起处理。
- **适用**：封面页、动态开场。
- 来源：https://www.douyin.com/video/7488345993621163304

## 三、RonniePPT（PowerPoint，粉丝 13.1 万）

- **做法**：纯效果展示，未讲步骤。可复现思路：同一图片复制多张拼阵列 + 大写字母拉间距标题 + 浮现类动画。

## 四、三位博主的共同高频技法（总结）

1. **形状图片填充**：把照片填进梯形、三角形、泪滴、圆环、圆角矩形等形状，是出现率最高的创意排版手法。
2. **合并形状 - 剪除**：做镂空字、镂空圆环；注意多选顺序（先底形后文字）。
3. **蒙版 / 渐变透明**：图片配文字时先想蒙版，统一色调、救废图。
4. **平滑切换（Morph）**：做旋转、变形、谢幕过渡；改过顶点的对象要用 `!!同名` 强制匹配防闪烁。
5. **分层动画**：背景、形状、文字分层设不同速度，做视差与浮现。
